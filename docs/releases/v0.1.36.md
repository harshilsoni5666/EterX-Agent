# EterX v0.1.36

- Connect agents as Telegram bots with private account pairing and file delivery.
- Improve chat memory, context continuity, steering, queued messages, and saved chat recovery.
- Add chat controls for compacting context, plan mode, usage, workspace selection, and per-agent tools.
- Improve Files, Review, browser, and side-chat workspace panels and attachment handling.
- Add managed terminal controls for waiting, checking output, continuing in the background, and stopping commands.
- Improve desktop startup, storage, installers, and packaging.
- Fix Gemini model pagination, terminal environment types, animated menu types, and optional Live Agent context handling.
- Require the complete integration suite and TypeScript validation before the native release builds start.

Native packages support Windows, macOS, and Linux on x64 and ARM64. The release includes updater metadata and a SHA-256 checksum manifest.
