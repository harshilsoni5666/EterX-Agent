# EterX v0.1.37

- Fix provider prompt caching across OpenAI, Gemini, Anthropic, and Grok, including invalid OpenAI retention values and provider-specific cache request rules.
- Recover once from truncated Gemini streams while preserving completed work and discarding incomplete responses.
- Improve model-specific reasoning controls and avoid retrying malformed provider requests across unrelated API routes.
- Improve Telegram bot behavior and runtime guidance with useful progress updates, mobile-friendly previews, evidence correction, and continuity for notes, questions, and delivered files.
- Remove automatic thumbs-up reactions and conversation headers from new Telegram bot replies.

Native packages support Windows, macOS, and Linux on x64 and ARM64. The release includes updater metadata and a SHA-256 checksum manifest.
