# EterX v0.1.38

- Preserve streamed function-call arguments exactly and normalize optional tool arguments before validation, preventing malformed calls and rejected file edits across agent types.
- Route OpenAI reasoning models through the Responses API with tool continuation support, and recover from unsupported optional request hints on compatible providers.
- Improve startup polling recovery and isolate model and thinking capabilities between the main agent and subagents.

Native packages support Windows, macOS, and Linux on x64 and ARM64. The release includes updater metadata and a SHA-256 checksum manifest.
